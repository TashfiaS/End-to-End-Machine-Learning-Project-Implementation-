# End-to-End-Machine-Learning-Project-Implementation-


### Prerequisites

- Anaconda: https://www.anaconda.com/download  
- Git: https://git-scm.com/downloads  
- Visual Studio Code: https://code.visualstudio.com/download  

### Database Used
- MongoDB: https://www.mongodb.com/products/platform/atlas-database

### Dataset used
- Kaggle: https://www.kaggle.com/datasets/moro23/easyvisa-dataset

### Clone the Repository

```bash
git clone https://github.com/TashfiaS/End-to-End-Machine-Learning-Project-Implementation-.git
cd End-to-End-Machine-Learning-Project-Implementation-
```

### Create Conda Environment
```bash
conda create -n visa2 python=3.10 -y
```
```bash
conda activate visa2
```

```bash
pip install -r requirements.txt
```
